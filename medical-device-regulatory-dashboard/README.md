# Medical Device Regulatory Dashboard

**Author: Shraddha Yadav**

An Excel analytics project exploring **200 medical device records**, covering **15 device types, four device classes and ten countries**. The dashboard summarises regulatory status, complaints, adverse events and recall flags to support data review.

## Project Files

- [View Project Report (PDF)](./Shraddha_Yadav_Regulatory_Dashboard_Project_Report%281%29.pdf)
- [Open Excel Dashboard](./Shraddha_Dashboard_FINAL2%281%29.xlsx)

## Tools and Features

- Microsoft Excel and SUMPRODUCT-based summaries.
- Five KPI cards and six dashboard charts.
- Four dropdown controls: country, device type, device class and notified body.
- Device-type/status cross-tabulation and analysis of recorded approval years.
- Supporting analysis of UDI assignment and postmarket-study requirements.

## Key Results

| Measure | Result |
| --- | ---: |
| Device records | 200 |
| Records marked Approved | 56 (28%) |
| Records flagged Recall Required | 110 (55%) |
| Reported complaints | 15,488 |
| Reported adverse events | 3,898 |
| Average adverse events per record | 19.49 |

**Patient Monitor** has the highest complaint total at **1,405**, while **ECG Machine** has the highest adverse-event total at **329**.

## How to Use

Open the PDF report to review the findings and methodology. To explore the dashboard, open the Excel file link, download the workbook and open it in Microsoft Excel. Allow formulas to recalculate before using the dropdown controls.

Detailed calculations, filter behavior, data-quality observations and recommendations are documented in the report.
