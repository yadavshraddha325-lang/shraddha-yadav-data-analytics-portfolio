# UK Greenhouse Gas Emissions Dashboard — 7,000 Records

**Author: Shraddha Yadav**

An Excel analytics project exploring a **7,000-record working extract with 19 fields covering 2005–2023**. The dashboard helps council officers, sustainability teams and other readers compare greenhouse-gas emissions by geography, year, sector and gas.

## Project Files

- [Download Excel Dashboard](./ShraddhaYadav_UKDashboard_7000_REAL_Pivots_Slicers.xlsx)
- [View Project Report (PDF)](./ShraddhaYadav_UKDashboard_7000_Report.pdf)

## Tools and Features

- **Microsoft Excel:** eight native PivotTables and eight dashboard charts.
- **Five slicers:** Country, Region, Calendar Year, Sector and Greenhouse gas.
- **Six KPI cards:** territorial emissions, records in view, scope-of-influence emissions, CO2 emissions, average emissions per record and CO2 share.
- Analysis of **eight sectors** and **three gases: CO2, CH4 and N2O**.
- Supporting dataset, data dictionary, source documentation and project report.

## Findings Across the Full Working Extract

| Measure | Result |
| --- | ---: |
| Records analysed | 7,000 |
| Territorial emissions | 161,705.23 kt CO2e |
| CO2 share of territorial emissions | 97.96% |
| Largest sector by territorial emissions | Transport |

These totals combine the included records across multiple years. They are not annual UK totals or representative national estimates.

## How to Use

1. Open the workbook link above, select **Download raw file** on GitHub and open it in Microsoft Excel.
2. Select the **Dashboard** sheet. The saved view has **Sector = Commercial**, showing 1,007 records.
3. Use each slicer's **Clear Filter** button to explore all 7,000 records, then select your preferred filters.
4. Use **Data → Refresh All** after updating source data. The PDF explains the methodology, audience and dashboard design.

Dashboard KPI cards reflect the selected filters; the findings above describe the full working extract.
